## 素材与运行时

翻译仓的 `translations/images/ui_images` 保存最终原生尺寸 PNG 和校验清单；生图原件、提示词、导出和验收截图放在忽略的 `.local/common-ui-images`。图片内容使用内置 imagegen 生成；.NET 图像处理只用于裁出输出、恢复原生尺寸、生成同一 alpha 的白色高光、图集排布与检查。

普通 Image 按 Sprite 名、尺寸及原始 RGBA 像素 SHA-256 匹配。替换保留 pivot、pixelsPerUnit、border 和过滤模式，跟踪游戏换图，支持底部导航状态变化。

Spine 按 SkeletonDataAsset、图集名称、标题 region 及其旋转/尺寸/trim offset/原始像素匹配。运行时从当前图集回读，再只替换标题矩形和已有 1 像素挤出边缘。由此继续使用当前人物、活动封面与装饰，不安装整张过时图集。支持实机使用的 Spine 4.0、Straight Alpha、0/90 度打包；单 renderer 使用 OverrideTexture，多 renderer 使用 CustomTextureOverride。保持骨架、动画、材质、shader 与点击事件。源标题变化时跳过并记录一次警告。

服务在 Unity 主线程每 250ms 检查，单轮最多一张新源素材 GPU 回读；成功和不匹配均缓存。恢复时只移除自己仍拥有的 override，不覆盖其他组件/模组已经改过的状态。材质和 SkeletonData 不共享修改。

切换页面时，Unity 会回收只由托管缓存或非序列化 override 持有的动态图片，导致旧缓存指向已销毁对象，标题恢复日文。生成的 Sprite、PNG 纹理和替换图集使用 `DontUnloadUnusedAsset`；缓存再次使用前检查原对象身份和替换对象存活状态。原素材销毁且没有组件继续持有覆盖时释放替换缓存；关闭插件时统一清理。纯图标与带字按钮可能同名，因此先按原生尺寸过滤，再校验源像素。

## 排版精修

底部导航采用同组 imagegen 字体参照，每个状态的可见字高约 24 像素、统一中心。未选中底板保留原始轮廓和约 230/255 的半透明 alpha，边框与首尾圆角沿用原素材。首页三个按钮的图案尺寸、标题字高约 20 像素和标题基线统一，分别生成图案与字样后组合。

任务页保留用户认可的“任务”“联合演习”原图。“活动”参考“任务”重新生成细描边，填充字高约 46 像素；“巡逻”缩到约 42 像素，“种族交流会”“菲尼斯塔”轻微调整到约 46 像素。只对 imagegen 字样裁切、缩放和定位；保持原 Spine attachment 的尺寸、偏移、动画和白色高光。字样按未裁切 attachment 中心摆放，不拉伸按钮背景。

## 构建和安装

```powershell
dotnet build TSKHook.csproj -c Release '-p:GamePath=E:\Games\DMM\Twinkle_StarKnightsX'
dotnet run --project Extensions/Tests/UiImagePackageTest -c Release -- E:\Codes\TSKHook-UITranslations\translations\images\ui_images
```

开发版 1.6.0 起插件构建仅生成 `TSKHook.dll`；`ui_images` 数据由翻译仓独立图片包提供。先退出游戏并备份现有插件，把 DLL 放入 `BepInEx/plugins/TSKHook.dll`，把 `ui_images` 放入 `BepInEx/plugins/TSKHook/ui_images`，再启动游戏。已有文本包、字体和配置无需覆盖。

原生尺寸检查及资源清单通过独立校验测试。未公开发布或提交推送。
